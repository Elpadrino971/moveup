# 🤖 MoovUp Now - Coach IA "Moov"

## 🎯 Vision

**Moov** est ton coach personnel IA, disponible 24/7, qui connaît ton profil, tes objectifs, ton historique et te guide de manière personnalisée. C'est comme avoir un personal trainer, un nutritionniste et un pote motivant dans ta poche.

### Différenciation Unique

**Concurrent le plus proche :** ChatGPT (général, pas contexte sport)

**Notre avantage :**
- 🎯 **Contexte complet** - Connaît ton profil, historique sessions, trust level, objectifs
- 📊 **Données temps réel** - Accès à tes stats santé (pas, cardio, glycémie si diabétique)
- 🤝 **Social intégré** - Peut suggérer sessions avec binômes, comparer avec communauté
- 💰 **Gamification** - Donne des MoovCoins pour défis réussis
- 🎮 **Actionnable** - Peut booker sessions, créer objectifs, inviter binômes

## 🔧 Implémentation Technique

### Architecture

```typescript
// Service chatAI.ts

import OpenAI from 'openai';
import { supabase } from './supabase';

class CoachMoovAI {
  private openai: OpenAI;

  constructor() {
    this.openai = new OpenAI({
      apiKey: process.env.OPENAI_API_KEY,
    });
  }

  // Récupérer le contexte complet de l'utilisateur
  async getUserContext(userId: string) {
    const [profile, sessions, health, objectives, social] = await Promise.all([
      this.getProfile(userId),
      this.getRecentSessions(userId, 30), // 30 derniers jours
      this.getHealthData(userId, 7), // 7 derniers jours
      this.getActiveObjectives(userId),
      this.getSocialContext(userId),
    ]);

    return {
      profile,
      sessions,
      health,
      objectives,
      social,
      timestamp: new Date().toISOString(),
    };
  }

  // Générer réponse IA
  async chat(userId: string, userMessage: string) {
    const context = await this.getUserContext(userId);
    const chatHistory = await this.getChatHistory(userId, 10); // 10 derniers messages

    const systemPrompt = this.buildSystemPrompt(context);

    const completion = await this.openai.chat.completions.create({
      model: 'gpt-4-turbo', // ou gpt-4o pour multimodal
      messages: [
        { role: 'system', content: systemPrompt },
        ...chatHistory,
        { role: 'user', content: userMessage },
      ],
      temperature: 0.7,
      max_tokens: 500,
      functions: this.getAvailableFunctions(), // Function calling
    });

    const response = completion.choices[0].message;

    // Si function call (booking session, création objectif, etc.)
    if (response.function_call) {
      await this.handleFunctionCall(userId, response.function_call);
    }

    // Sauvegarder dans historique
    await this.saveChatMessage(userId, userMessage, response.content);

    return response.content;
  }

  // Construire le prompt système avec contexte
  buildSystemPrompt(context: UserContext): string {
    return `Tu es Moov, le coach personnel IA de ${context.profile.username} sur MoovUp Now.

PROFIL UTILISATEUR:
- Âge: ${context.profile.age} ans
- Objectif principal: ${context.profile.main_goal}
- Trust Level: ${context.profile.trust_level}
- Sports favoris: ${context.profile.favorite_sports.join(', ')}
- Diabétique: ${context.profile.has_diabetes ? 'Oui (Type ' + context.profile.diabetes_type + ')' : 'Non'}

STATS RÉCENTES (7 jours):
- Sessions: ${context.sessions.length}
- Distance totale: ${context.sessions.reduce((a, s) => a + s.distance, 0)}km
- Calories: ${context.health.total_calories}
- Pas moyens/jour: ${context.health.avg_steps}
${context.profile.has_diabetes ? `- Glycémie moyenne: ${context.health.avg_glucose} mg/dL` : ''}

CO-OBJECTIFS ACTIFS:
${context.objectives.map(o => `- ${o.title} (${o.status})`).join('\n')}

TON RÔLE:
1. Motiver et encourager de manière positive
2. Donner des conseils personnalisés basés sur les données
3. Prévenir les blessures et promouvoir la sécurité
4. Aider à atteindre les objectifs
5. Gamifier l'expérience (MoovCoins, badges, défis)
${context.profile.has_diabetes ? '6. PRIORITÉ: Sécurité diabète - alerter si glycémie problématique' : ''}

STYLE:
- Amical et motivant (emojis OK)
- Concis et actionnable
- Empathique si difficulté
- Célèbre les victoires

INTERDICTIONS:
- Ne JAMAIS donner de diagnostics médicaux
- Toujours recommander médecin si blessure/douleur persistante
- Ne pas pousser à l'overtraining
- Respecter les jours de repos`;
  }

  // Functions disponibles (OpenAI Function Calling)
  getAvailableFunctions() {
    return [
      {
        name: 'book_session',
        description: 'Réserver une session sportive pour l\'utilisateur',
        parameters: {
          type: 'object',
          properties: {
            session_id: { type: 'string' },
            confirmation_message: { type: 'string' },
          },
          required: ['session_id'],
        },
      },
      {
        name: 'create_objective',
        description: 'Créer un nouvel objectif pour l\'utilisateur',
        parameters: {
          type: 'object',
          properties: {
            title: { type: 'string' },
            target_value: { type: 'number' },
            duration_days: { type: 'number' },
          },
          required: ['title', 'target_value'],
        },
      },
      {
        name: 'award_moovcoins',
        description: 'Donner des MoovCoins à l\'utilisateur pour un accomplissement',
        parameters: {
          type: 'object',
          properties: {
            amount: { type: 'number' },
            reason: { type: 'string' },
          },
          required: ['amount', 'reason'],
        },
      },
      {
        name: 'send_glucose_alert',
        description: 'Envoyer une alerte glycémie si diabétique et valeur problématique',
        parameters: {
          type: 'object',
          properties: {
            glucose_value: { type: 'number' },
            alert_type: { type: 'string', enum: ['hypo', 'hyper'] },
            recommendations: { type: 'array', items: { type: 'string' } },
          },
          required: ['glucose_value', 'alert_type'],
        },
      },
    ];
  }

  // Gérer les function calls
  async handleFunctionCall(userId: string, functionCall: any) {
    const { name, arguments: args } = functionCall;
    const parsedArgs = JSON.parse(args);

    switch (name) {
      case 'book_session':
        await this.bookSession(userId, parsedArgs.session_id);
        break;
      case 'create_objective':
        await this.createObjective(userId, parsedArgs);
        break;
      case 'award_moovcoins':
        await this.awardMoovCoins(userId, parsedArgs.amount, parsedArgs.reason);
        break;
      case 'send_glucose_alert':
        await this.sendGlucoseAlert(userId, parsedArgs);
        break;
    }
  }

  // Notifications proactives
  async sendProactiveMessages() {
    // Exemples de triggers automatiques

    // 1. Série en danger
    const usersWithStreakAtRisk = await this.getUsersWithStreakAtRisk();
    for (const user of usersWithStreakAtRisk) {
      await this.sendMessage(user.id,
        `⚠️ Ta série de ${user.streak_days} jours est en danger !
        Il te reste 4h pour valider un objectif aujourd'hui.
        Une petite session de 15min suffit ! 💪`
      );
    }

    // 2. Météo impact session
    const usersWithSessionsAffected = await this.getUsersWithWeatherImpact();
    for (const user of usersWithSessionsAffected) {
      await this.suggestAlternatives(user);
    }

    // 3. Nouveau record perso
    const usersWithNewRecords = await this.getUsersWithNewRecords();
    for (const user of usersWithNewRecords) {
      await this.celebrateRecord(user);
    }

    // 4. Binôme en difficulté
    const usersWithStrugglingPartner = await this.getUsersWithStrugglingPartner();
    for (const user of usersWithStrugglingPartner) {
      await this.suggestSupportPartner(user);
    }
  }
}

export default new CoachMoovAI();
```

### Base de Données

```sql
-- Table conversations IA
CREATE TABLE ai_conversations (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id UUID REFERENCES profiles(id),
  message TEXT NOT NULL,
  is_user BOOLEAN NOT NULL, -- true = user, false = Moov
  created_at TIMESTAMP DEFAULT NOW(),
  tokens_used INT, -- Tracking coût
  function_called TEXT, -- Si function call
  INDEX idx_ai_conv_user (user_id, created_at DESC)
);

-- Table actions IA (function calls historique)
CREATE TABLE ai_actions (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  conversation_id UUID REFERENCES ai_conversations(id),
  user_id UUID REFERENCES profiles(id),
  action_type TEXT NOT NULL, -- 'book_session', 'create_objective', etc.
  action_data JSONB,
  success BOOLEAN DEFAULT true,
  created_at TIMESTAMP DEFAULT NOW()
);

-- Table préférences IA
CREATE TABLE ai_user_preferences (
  user_id UUID PRIMARY KEY REFERENCES profiles(id),
  response_style TEXT DEFAULT 'motivating', -- 'motivating', 'analytical', 'friendly'
  tone TEXT DEFAULT 'casual', -- 'casual', 'formal'
  proactive_messages BOOLEAN DEFAULT true,
  voice_enabled BOOLEAN DEFAULT false,
  updated_at TIMESTAMP DEFAULT NOW()
);
```
