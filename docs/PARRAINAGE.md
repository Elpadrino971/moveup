## 🛡️ Anti-Abus & Fraude

### Détection Automatique

```typescript
// Anti-fraude système

class ReferralFraudDetection {
  async checkFraud(referrerId: string, referredId: string) {
    const flags = [];

    // 1. Même IP
    if (await this.sameIP(referrerId, referredId)) {
      flags.push('SAME_IP');
    }

    // 2. Même device fingerprint
    if (await this.sameDevice(referrerId, referredId)) {
      flags.push('SAME_DEVICE');
    }

    // 3. Email jetable
    if (await this.isDisposableEmail(referredId)) {
      flags.push('DISPOSABLE_EMAIL');
    }

    // 4. Inscription trop rapide (< 1 min après clic lien)
    if (await this.tooFastSignup(referredId)) {
      flags.push('TOO_FAST');
    }

    // 5. Pattern d'abus (parrain a déjà 50+ filleuls inactifs)
    if (await this.suspiciousPattern(referrerId)) {
      flags.push('SUSPICIOUS_PATTERN');
    }

    // 6. Filleul jamais actif (0 sessions après 7 jours)
    if (await this.neverActive(referredId, 7)) {
      flags.push('NEVER_ACTIVE');
    }

    if (flags.length >= 2) {
      // Fraude probable
      await this.blockRewards(referrerId, referredId);
      await this.notifyModerationTeam(flags);
    }

    return flags;
  }
}
```

### Règles Anti-Abus

**Activation des récompenses :**
```
Récompenses parrain débloquées UNIQUEMENT si :
✅ Filleul confirme email
✅ Filleul complète onboarding (4 étapes)
✅ Filleul fait ≥1 session dans les 30 jours
✅ Pas de flags fraude

Sinon :
❌ Récompenses suspendues
❌ Investigation manuelle si pattern suspect
```

**Limites :**
```
Max 10 filleuls/semaine/parrain
→ Prévient spam massif

Max 100 filleuls/mois/parrain
→ Force validation qualité

Commission Premium suspendue si :
• Filleul annule Premium < 2 mois
→ Évite gaming système
```
