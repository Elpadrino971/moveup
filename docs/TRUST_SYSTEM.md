# 🛡️ MoovUp Now - Système de Confiance Progressif

## 🎯 Objectif

**Problème :** Éviter les dérives (drague, harcèlement) tout en permettant des rencontres sportives saines entre tous les utilisateurs.

**Solution :** Un système de déblocage progressif basé sur la fiabilité prouvée, avec des restrictions initiales strictes.

---

## 📊 Les 5 Niveaux de Confiance

### 🆕 Niveau 1 - DÉBUTANT (0-4 sessions complétées)

**Badge :** 🔰 Débutant

**Restrictions :**
- ✅ **Même sexe uniquement** (homme-homme, femme-femme)
- ✅ **OU groupes mixtes** (3+ personnes minimum)
- ❌ **Sexe opposé en binôme INTERDIT**

**Objectif :** Prouver sa fiabilité dans un cadre sécurisé

**Message à l'utilisateur :**
> "Pour ta sécurité et celle des autres, commence par des sessions avec des personnes du même sexe ou en groupe. Après 5 sessions réussies, tu débloqueras plus de possibilités !"

---

### ⚡ Niveau 2 - CONFIRMÉ (5-9 sessions complétées)

**Badge :** ⚡ Confirmé

**Déblocages :**
- ✅ **Sexe opposé en groupe** (3+ personnes minimum)
- ✅ Même sexe en binôme (toujours autorisé)

**Conditions de déblocage :**
- ✅ 5 sessions complétées minimum
- ✅ Note moyenne ≥ 4.0/5.0
- ✅ 0 signalement

**Message à l'utilisateur :**
> "Bravo ! Tu peux maintenant rejoindre des groupes mixtes. Continue comme ça pour débloquer les sessions en binôme avec tous !"

---

### ✅ Niveau 3 - VÉRIFIÉ (10-19 sessions complétées)

**Badge :** ✅ Vérifié

**Déblocages :**
- ✅ **Sexe opposé en binôme** (1-1 autorisé)
- ✅ Toutes les options de matching

**Conditions de déblocage :**
- ✅ 10 sessions complétées minimum
- ✅ Note moyenne ≥ 4.5/5.0
- ✅ 0 signalement
- ✅ Compte vérifié (email + téléphone)
- ✅ Photo de profil validée

**Message à l'utilisateur :**
> "Tu es maintenant un membre vérifié ! Tu as accès à toutes les options de matching. Continue de respecter la communauté !"

---

### 🏆 Niveau 4 - EXPERT (20-49 sessions complétées)

**Badge :** 🏆 Expert

**Avantages :**

**Badge :** 👑 Legend

**Avantages :**

**Conditions :**
- ✅ 50 sessions complétées minimum
- ✅ Note moyenne ≥ 4.8/5.0
- ✅ 0 signalement non résolu
- ✅ Compte actif depuis 3+ mois

## 🚨 Règles de Sécurité Strictes

### 1. Validation Obligatoire par QR Code

**Pour toutes les sessions :**
- Scanner le QR code de l'autre personne sur place
- Les deux participants doivent scanner
- Sans scan → la session ne compte pas

**Pourquoi :**
- Preuve de présence physique
- Évite les faux profils
- Valide que la rencontre a bien eu lieu

---

### 2. Système de Signalement

**Types de signalements :**
- 🚫 Comportement inapproprié
- 💔 Harcèlement / drague insistante
- 👻 Non présentation (no-show)
- 🔞 Contenu sexuel / déplacé
- 🤥 Faux profil
- 📍 Lieu non sécurisé

**Actions automatiques :**

| Signalements | Action |
|--------------|--------|
| 1 signalement | ⚠️ Avertissement + enquête manuelle |
| 2 signalements | 🔒 Retour Niveau 1 temporaire (enquête) |
| 3 signalements | 🚫 Suspension 7 jours |
| 5 signalements | ❌ Bannissement permanent |

---

### 3. Dégradation de Niveau

**Tu peux perdre un niveau si :**
- Signalement confirmé → Retour Niveau 1
- Note moyenne < 3.5/5 → Avertissement
- 2 no-shows consécutifs → Avertissement
- Comportement détecté par IA modération → Enquête

**Remonter de niveau :**
- Compléter 5 sessions avec note ≥ 4.5/5
- Respecter la charte pendant 30 jours
- Répondre positivement à l'enquête

---

### 4. Groupes Mixtes : Exception Sécurisée

**Règle :** Les groupes de 3+ personnes sont **toujours autorisés**, même pour les Niveau 1.

**Pourquoi :**
- Sécurité du nombre
- Moins de risque de dérive
- Permet de mixer même aux débutants

**Conditions groupe :**
- Minimum 3 participants confirmés
- Lieu public recommandé
- QR code obligatoire pour tous

---

### 5. Lieux Publics Recommandés

**Système d'alerte intelligente :**

| Type de lieu | Action |
|--------------|--------|
| Parc public | ✅ Recommandé |
| Salle de sport | ✅ Recommandé |
| Stade public | ✅ Recommandé |
| Rue fréquentée | ⚠️ OK mais warning |
| Domicile privé | 🚫 Warning fort (Niveau 1-2) |
| Lieu isolé | 🚫 Warning + demande confirmation |

**Message si lieu privé détecté (Niveau 1-2) :**
> "⚠️ Attention : Pour ta sécurité, nous recommandons un lieu public pour les premières sessions. Veux-tu vraiment continuer ?"

## 🎓 Système de Parrainage (Niveau 5)

**Concept :** Les Legends peuvent parrainer des débutants.

**Fonctionnement :**
1. Un Legend peut inviter un Niveau 1-2
2. Fait une session ensemble
3. Le débutant gagne +2 sessions de progression
4. Le Legend gagne +50 points

**Sécurité :**
- Maximum 1 parrainage par semaine
- Le Legend perd son statut si le parrainé se fait bannir
- Incite à bien choisir qui parrainer

## 📊 Calcul du Niveau

### Formule de Progression

```typescript
function calculateTrustLevel(user: User): TrustLevel {
  const {
    sessionsCompleted,
    averageRating,
    warningsCount,
    isVerified,
    accountAge
  } = user;

  // Niveau 1 : Débutant
  if (sessionsCompleted < 5) return 1;

  // Niveau 2 : Confirmé
  if (
    sessionsCompleted < 10 ||
    averageRating < 4.0 ||
    warningsCount > 0
  ) return 2;

  // Niveau 3 : Vérifié
  if (
    sessionsCompleted < 20 ||
    averageRating < 4.5 ||
    !isVerified
  ) return 3;

  // Niveau 4 : Expert
  if (
    sessionsCompleted < 50 ||
    warningsCount > 1
  ) return 4;

  // Niveau 5 : Legend
  if (
    sessionsCompleted >= 50 &&
    averageRating >= 4.8 &&
    warningsCount === 0 &&
    accountAge >= 90 // 3 mois
  ) return 5;

  return 3; // Défaut
}
```

### Vérification de Permission

```typescript
function canMatchWithOppositeGender(
  userLevel: number,
  sessionType: 'one-on-one' | 'group'
): boolean {
  // Groupes toujours autorisés
  if (sessionType === 'group') return true;

  // Niveau 3+ peut matcher en binôme
  return userLevel >= 3;
}
```

## 🔐 Points Clés de Sécurité

### ✅ Ce qui PROTÈGE

1. **Progression forcée** → Pas de raccourci
2. **QR code obligatoire** → Preuve de présence réelle
3. **Groupes mixtes autorisés** → Socialisation safe dès le début
4. **Signalement facile** → 1 bouton, toujours visible
5. **Dégradation possible** → Comportement = conséquences
6. **Historique visible** → Transparence totale

### ❌ Ce qui ÉVITE

1. Faux profils → Vérification email/tel requise Niveau 3
2. Drague/harcèlement → Restrictions Niveau 1-2
3. Lieux isolés → Warning automatique
4. No-shows répétés → Perte de points/niveau
5. Comportements toxiques → Signalement → Ban
6. Profils jetables → Compte âge minimum pour Niveau 5
