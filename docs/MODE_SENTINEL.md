# 🆘 MoovUp Now - Mode Sentinel (Sécurité Renforcée)

## 🎯 Vision

Le **Mode Sentinel** est un système de sécurité renforcé qui protège les utilisateurs pendant leurs sessions sportives, particulièrement lors de rencontres 1-on-1 avec des inconnus. C'est le "bodyguard virtuel" de MoovUp Now.

### Problème à Résoudre

**Barrières psychologiques :**
- 67% des femmes hésitent à rejoindre sessions 1-on-1 avec inconnus (étude interne)
- Parents inquiets pour leurs enfants 16-18 ans
- Crainte d'agression, vol, ou comportements inappropriés

**Risques réels :**
- Sessions dans lieux isolés
- Pas de témoin
- Personne au courant de la localisation
- Difficulté à appeler à l'aide en situation dangereuse

### Solution : Mode Sentinel

**Un système complet de protection qui :**
- 📍 Track la localisation en temps réel (consentement)
- 👥 Alert automatiquement des contacts d'urgence
- ⏱️ Vérifie que tout va bien à intervalles réguliers
- 🚨 Déclenche alertes si anomalie
- 🔴 Bouton SOS discret et rapide

### 5. Détection Automatique d'Anomalies

**IA de détection :**
```typescript
// Système de détection intelligent

class SentinelAnomalyDetection {
  async detect(sessionId: string) {
    const session = await this.getSession(sessionId);
    const user = session.user;
    const location = await this.getCurrentLocation(user.id);

    const anomalies = [];

    // 1. Déplacement hors zone prévue
    const plannedArea = session.location;
    const distance = this.calculateDistance(location, plannedArea);
    if (distance > 2) { // > 2km du lieu prévu
      anomalies.push({
        type: 'LOCATION_DEVIATION',
        severity: 'HIGH',
        message: 'User s\'est éloigné de +2km du lieu prévu',
      });
    }

    // 2. Vitesse anormale (transport motorisé non prévu)
    const speed = await this.getCurrentSpeed(user.id);
    if (session.sport.type === 'running' && speed > 30) { // > 30 km/h
      anomalies.push({
        type: 'ABNORMAL_SPEED',
        severity: 'MEDIUM',
        message: 'Vitesse inhabituelle pour ce sport (transport?)',
      });
    }

    // 3. Immobilité totale prolongée
    const lastMovement = await this.getLastMovement(user.id);
    if (Date.now() - lastMovement > 20 * 60 * 1000) { // 20 min sans mouvement
      anomalies.push({
        type: 'NO_MOVEMENT',
        severity: 'HIGH',
        message: 'Aucun mouvement depuis 20 min',
      });
    }

    // 4. Batterie critique
    const battery = await this.getBatteryLevel(user.id);
    if (battery < 10) {
      anomalies.push({
        type: 'LOW_BATTERY',
        severity: 'MEDIUM',
        message: 'Batterie < 10% - risque perte contact',
      });
      await this.alertContacts(user.id, 'LOW_BATTERY');
    }

    // 5. Pattern suspect sur binôme
    const partner = session.partner;
    const partnerHistory = await this.getPartnerHistory(partner.id);
    if (partnerHistory.sos_count > 2) { // 2+ SOS sur sessions précédentes
      anomalies.push({
        type: 'PARTNER_HISTORY',
        severity: 'CRITICAL',
        message: 'Binôme a déjà eu 2+ alertes SOS',
      });
      // Trigger check-in immédiat
      await this.forceCheckIn(user.id);
    }

    return anomalies;
  }
}
```
